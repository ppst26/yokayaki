# Specification: Ingredient Procurement & Cost Management System (stock-management.md)

เอกสารข้อกำหนดและการออกแบบ **ระบบจัดการต้นทุนจัดซื้อวัตถุดิบ (Ingredient Procurement System)** สำหรับบันทึกการสั่งซื้อวัตถุดิบทำอาหาร, คำนวณต้นทุนวัตถุดิบดิบจริง และการแสดงผลรายงานในระบบ Yokayaki POS

---

## 1. ปรัชญาและแนวคิดหลัก (Core Architecture & Flow Revision)

แกนหลักของระบบเน้น **การบันทึกต้นทุนจัดซื้อวัตถุดิบจริงในการทำเมนู (Raw Ingredient Procurement)** เพื่อให้เจ้าของร้านเห็นต้นทุนวัตถุดิบจริงของร้านอย่างแม่นยำ:

- **การปรับเปลี่ยน Flow ทำงาน (Streamlined Flow):** 
  - ยกเลิกแท็บนับสต็อกแบบซ้ำซ้อนในหน้านี้ (`รายการสต็อกคงเหลือ` และ `ประวัติการปรับสต็อก`) โดยย้ายการจัดการนับสต็อกจานอาหารไปไว้ที่หน้า **Menu Manager (`MenuManager.tsx`)** โดยตรง
  - หน้า **`StockManager`** ปรับบทบาทมุ่งเน้น **การบริหารต้นทุนและประวัติการสั่งซื้อวัตถุดิบ (Purchase Orders - PO)** เต็มรูปแบบ
- **จัดกลุ่มตามรอบการสั่งซื้อ (Purchase Orders / PO):** บันทึกการจัดซื้อวัตถุดิบแต่ละรอบ (Header + Detail)
- **ระบบตัวกรองวันเวลา (Date Range Filter & Custom DatePicker):** สามารถเลือกดูรายงานและประวัติจัดซื้อตามช่วงเวลาที่กำหนดได้ยืดหยุ่น

---

## 2. โครงสร้างฐานข้อมูล (Database Schema)

### 2.1 ตาราง `purchase_orders` (Header รายการสั่งซื้อแต่ละรอบ)

ตารางหลักสำหรับเก็บข้อมูลภาพรวมของบิลการสั่งซื้อวัตถุดิบแต่ละรอบ:

| Column Name | Data Type | Key / Constraint | Description |
| :--- | :--- | :--- | :--- |
| `id` | `BIGSERIAL` | Primary Key | รหัสออเดอร์จัดซื้อ (แสดงผลเป็น Unique ID เช่น `PO-0001`, `PO-0002`) |
| `purchase_date` | `DATE` | NOT NULL | วันที่สั่งซื้อ/จัดซื้อวัตถุดิบ |
| `buyer_name` | `VARCHAR(255)` | NOT NULL | ชื่อพนักงานหรือผู้ทำรายการสั่งซื้อ |
| `total_cost` | `DECIMAL(10,2)`| NOT NULL, DEFAULT 0 | ยอดรวมเงินจัดซื้อทั้งบิล |
| `note` | `TEXT` | DEFAULT NULL | หมายเหตุเพิ่มเติม (เช่น ชื่อซัพพลายเออร์ หรือเลขใบเสร็จ) |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | เวลาที่บันทึกข้อมูลเข้าระบบ |

### 2.2 ตาราง `item_ingredients` (Detail รายการวัตถุดิบย่อย)

ตารางรายชื่อวัตถุดิบแต่ละรายการที่สั่งซื้อ ผูกเข้ากับ `purchase_orders`:

| Column Name | Data Type | Key / Constraint | Description |
| :--- | :--- | :--- | :--- |
| `id` | `BIGSERIAL` | Primary Key | ID รายการวัตถุดิบ |
| `purchase_order_id`| `BIGINT` | FK -> `purchase_orders.id` | อ้างอิงบิลสั่งซื้อ (ON DELETE CASCADE) |
| `name` | `VARCHAR(255)` | NOT NULL | ชื่อวัตถุดิบ (เช่น แซลมอน, ปลาซาบะ, เบียร์สด, เส้นโซบะ) |
| `quantity` | `DECIMAL(10,2)`| NOT NULL | จำนวนหน่วยที่สั่งซื้อ |
| `unit` | `VARCHAR(50)` | NOT NULL | หน่วยนับ (เช่น กก., ขีด, ถุง, แพ็ค, แผง, ขวด, ลัง, ลิตร) |
| `cost` | `DECIMAL(10,2)`| NOT NULL | ราคารวมวัตถุดิบรายการนี้ (= จำนวน × ราคาต่อหน่วย) |
| `purchase_date` | `DATE` | NOT NULL | วันที่จัดซื้อ |
| `buyer_name` | `VARCHAR(255)` | NOT NULL | ผู้จัดซื้อ |

## 3. รายละเอียด UI & ระบบกรองวันเวลา (UI Workflow & Date Filtering)

เมื่อเจ้าของร้านกดเลือกเมนู **"ต้นทุนวัตถุดิบ"** ใน Sidebar ระบบจะแสดงผลหน้าประวัติสั่งซื้อวัตถุดิบพร้อมตัวกรองรายงาน:

### 3.1 แถบตัวกรองช่วงเวลาและค้นหา (Filter & Search Bar)

1. **Dropdown เลือกช่วงเวลา (Date Range Preset):**
   - **ทั้งหมด (All Time):** แสดงประวัติจัดซื้อทั้งหมด
   - **วันนี้ (Today):** แสดงเฉพาะออเดอร์จัดซื้อของวันนี้
   - **รายสัปดาห์ (Weekly):** แสดงย้อนหลัง 7 วันล่าสุด
   - **รายเดือน (Monthly):** แสดงย้อนหลัง 30 วันล่าสุด
   - **3 เดือน (3 Months):** แสดงย้อนหลัง 90 วันล่าสุด
   - **6 เดือน (6 Months):** แสดงย้อนหลัง 180 วันล่าสุด
   - **กำหนดเอง (Custom Range):** เปิดใช้งาน DatePicker เลือกวันเริ่มต้นและวันสิ้นสุด

2. **Custom DatePicker (เมื่อเลือก 'กำหนดเอง'):**
   - ช่องเลือกวันที่เริ่มต้น (`startDate`) และ วันที่สิ้นสุด (`endDate`) สำหรับเจาะจงช่วงเวลาที่ต้องการตรวจสอบ

3. **ช่องค้นหา (Search Input):**
   - ค้นหาด้วยรหัส `PO-xxxx`, ชื่อผู้สั่งซื้อ, หรือข้อความในหมายเหตุ

4. **สรุปยอดเงินและจำนวนรายการ (Filter Summary Stats):**
   - แสดงจำนวนรายการที่กรองได้ และ ยอดรวมค่าใช้จ่ายจัดซื้อสุทธิในช่วงเวลานั้นๆ (เช่น `แสดง 5 รายการ | รวมค่าใช้จ่ายจัดซื้อ: 12,500 ฿`)

## 4. Modal บันทึกประวัติการสั่งซื้อวัตถุดิบ (Add Purchase Order Modal)

เมื่อกดปุ่ม **"เพิ่มรายการสั่งซื้อ"** จะมี Pop-up Modal แสดงขึ้นมา:

1. **ส่วนหัวบิล (Header Details):**
   - **วันที่สั่งซื้อ:** Date Picker กำหนดวันที่จัดซื้อได้
   - **ผู้สั่งซื้อ:** Input Text ระบุชื่อผู้ทำรายการ
   - **หมายเหตุ:** Input Text ระบุรายละเอียดเพิ่มเติม (Optional)

2. **ตารางกรอกรายการวัตถุดิบ (Dynamic Ingredient Rows):**
   - **ชื่อวัตถุดิบ:** พิมพ์ชื่อวัตถุดิบอิสระ (เช่น แซลมอน, ปลาซาบะ, เบียร์สด, เส้นโซบะ)
   - **จำนวน:** ระบุจำนวนหน่วย
   - **หน่วยนับ:** เลือกจาก Dropdown (`กก.`, `ขีด`, `ถุง`, `แพ็ค`, `แผง`, `ขวด`, `กล่อง`, `ลัง`, `ชิ้น`, `ลิตร`)
   - **ราคาต่อหน่วย:** ระบุราคาต่อ 1 หน่วย
   - **คำนวณอัตโนมัติ:** ระบบคำนวณราคารวมของแถวนั้นทันที (`จำนวน × ราคาต่อหน่วย`)
   - **ปุ่มเพิ่ม/ลบแถว:** กดเพิ่มรายการ (+) หรือกดลบแถว (ไอคอนถังขยะ) ได้ตามต้องการ

3. **สรุปยอดรวม (Total Cost Summary Box):**
   - คำนวณสรุปยอดเงินรวมวัตถุดิบทุกรายการแบบ Real-time ในกล่องสรุปสไตล์แบรนด์ Yokayaki Red

---

## 5. การเชื่อมโยงกับ Owner Dashboard

ข้อมูลการจัดซื้อจากตาราง `purchase_orders` และ `item_ingredients` จะส่งตรงไปแสดงผลใน **Dashboard เจ้าของร้าน**:

1. **Card สรุปยอดต้นทุนวัตถุดิบ:** รวมราคารวมจัดซื้อตามช่วงเวลาที่กรอง
2. **Top 3 วัตถุดิบต้นทุนสูงสุด:** แสดง 3 วัตถุดิบที่ใช้เงินซื้อมากที่สุดในช่วงเวลานั้นๆ
