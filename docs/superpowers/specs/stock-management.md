# Specification: Ingredient Procurement & Cost Management System (stock-management.md)

เอกสารข้อกำหนดและการออกแบบ **ระบบจัดการต้นทุนจัดซื้อวัตถุดิบ (Ingredient Procurement System)** สำหรับบันทึกการสั่งซื้อวัตถุดิบทำอาหาร, คำนวณต้นทุนวัตถุดิบดิบจริง และการแสดงผลรายงานในระบบ Mini POS

---

## 1. ปรัชญาและแนวคิดหลัก (Core Architecture & Concept)

แกนหลักของระบบเปลี่ยนจากการนับเฉพาะสต็อกจานอาหารสำเร็จรูป มาเป็นการ **บันทึกต้นทุนจัดซื้อวัตถุดิบจริงในการทำเมนู (Raw Ingredient Procurement)** เพื่อให้เจ้าของร้านเห็นต้นทุนวัตถุดิบจริงของร้าน:

- **บันทึกวัตถุดิบดิบยามสั่งเข้า:** เช่น แซลมอน, ปลาซาบะ, เบียร์สด, เส้นโซบะ, กุ้ง ฯลฯ
- **จัดกลุ่มตามรอบการสั่งซื้อ (Purchase Orders / PO):** ทุกครั้งที่มีการจัดซื้อวัตถุดิบ จะบันทึกเป็นบิลออเดอร์จัดซื้อ (Header + Items Detail)
- **วิเคราะห์ต้นทุนแม่นยำ:** นำยอดเงินจัดซื้อไปรวมคำนวณต้นทุนใน **Owner Dashboard** และรายงานวิเคราะห์ผลประกอบการ

---

## 2. โครงสร้างฐานข้อมูล (Database Schema)

### 2.1 ตาราง `purchase_orders` (Header รายการสั่งซื้อแต่ละรอบ)

ตารางหลักสำหรับเก็บข้อมูลภาพรวมของบิลการสั่งซื้อวัตถุดิบแต่ละรอบ:

| Column Name | Data Type | Key / Constraint | Description |
| :--- | :--- | :--- | :--- |
| `id` | `BIGSERIAL` | Primary Key | รหัสออเดอร์จัดซื้อ (แสดงผลเป็น Unique ID เช่น `PO-0001`, `PO-0002`) |
| `purchase_date` | `DATE` | NOT NULL | วันที่สั่งซื้อ/จัดซื้อวัตถุดิบ |
| `buyer_name` | `VARCHAR(255)` | NOT NULL | ชื่อพนักงานหรือผู้ทำรายการสั่งซื้อ |
| `total_cost` | `DECIMAL(10,2)`| NOT NULL, DEFAULT 0 | ยอดรวมเงินจัดซื้อทั้งบิล |
| `note` | `TEXT` | DEFAULT NULL | หมายเหตุเพิ่มเติม (เช่น ชื่อซัพพลายเออร์ หรือเลขใบเสร็จ) |
| `created_at` | `TIMESTAMPTZ` | NOT NULL | เวลาที่บันทึกข้อมูลเข้าระบบ |

### 2.2 ตาราง `item_ingredients` (Detail รายการวัตถุดิบย่อย)

ตารางรายชื่อวัตถุดิบแต่ละรายการที่สั่งซื้อ ผูกเข้ากับ `purchase_orders`:

| Column Name | Data Type | Key / Constraint | Description |
| :--- | :--- | :--- | :--- |
| `id` | `BIGSERIAL` | Primary Key | ID รายการวัตถุดิบ |
| `purchase_order_id`| `BIGINT` | FK -> `purchase_orders.id` | อ้างอิงบิลสั่งซื้อ (ON DELETE CASCADE) |
| `name` | `VARCHAR(255)` | NOT NULL | ชื่อวัตถุดิบ (เช่น แซลมอน, ปลาซาบะ, เบียร์สด, เส้นโซบะ) |
| `quantity` | `DECIMAL(10,2)`| NOT NULL | จำนวนหน่วยที่สั่งซื้อ |
| `unit` | `VARCHAR(50)` | NOT NULL | หน่วยนับ (เช่น กก., ขีด, ถุง, แพ็ค, แผง, ขวด, ลัง, ลิตร) |
| `cost` | `DECIMAL(10,2)`| NOT NULL | ราคารวมวัตถุดิบรายการนี้ (= จำนวน × ราคาต่อหน่วย) |
| `purchase_date` | `DATE` | NOT NULL | วันที่จัดซื้อ |
| `buyer_name` | `VARCHAR(255)` | NOT NULL | ผู้จัดซื้อ |

## 3. รายละเอียด UI & กระบวนการทำงาน (UI Workflow)

เมื่อเจ้าของร้านกดเลือกเมนู **"ต้นทุนวัตถุดิบ"** ในแถบเมนูด้านข้าง (Sidebar) ระบบจะนำเข้าสู่หน้าจอ `StockManager` โดยแสดงผลดังนี้:

### 3.1 ตารางรายการสั่งซื้อวัตถุดิบ (Purchase Orders Table - Default View)

- **หน้าเริ่มต้น (Default Tab):** เปิดเข้าหน้า **"ต้นทุนวัตถุดิบ (ประวัติการสั่งซื้อ)"** เป็นหน้าแรกทันที
- **ปุ่ม Action:** ปุ่ม **"เพิ่มรายการสั่งซื้อ"** สีเขียวเด่นชัด ชูจุดเด่นยามต้องการบันทึกวัตถุดิบใหม่
- **ตารางสรุปรายการสั่งซื้อ (Purchase Order Batch List):**
  - **เลขที่ออเดอร์ (Unique ID):** แสดงรหัส `PO-0001`, `PO-0002` เรียงตามลำดับล่าสุด
  - **วันที่สั่งซื้อ:** แสดงวันที่ในรูปแบบ วว/ดด/ปปปป
  - **ผู้ทำรายการ:** แสดงชื่อผู้สั่งซื้อ
  - **หมายเหตุ:** แสดงข้อความหมายเหตุสั้นๆ (ถ้ามี)
  - **ยอดเงินรวม:** แสดงยอดค่าใช้จ่ายรวม (฿) เป็นตัวหนาสีเขียว

### 3.2 รายละเอียดวัตถุดิบย่อยรายบิล (Expandable Sub-Table Detail)

- เมื่อคลิกที่แถวรายการสั่งซื้อ `PO-xxxx` แถวนั้นจะขยายลงมา (Expand)
- ดึงรายการวัตถุดิบจากตาราง `item_ingredients` มาแสดงเป็น **ตารางย่อย (Sub-table)**:
  - **ชื่อวัตถุดิบ:** (เช่น แซลมอนสด, ปลาซาบะ, เบียร์สดถัง)
  - **จำนวน:** (เช่น 5, 10, 2)
  - **หน่วยนับ:** (เช่น กก., ถุง, ลัง)
  - **ราคารวม:** ยอดเงินของวัตถุดิบแต่ละรายการ
- **แถบสรุป:** แสดงสรุปจำนวนรายการวัตถุดิบบนบิลนั้น และ ยอดเงินรวมทั้งสิ้น

### 3.3 Modal บันทึกประวัติการสั่งซื้อวัตถุดิบ (Add Purchase Order Modal)

เมื่อกดปุ่ม **"เพิ่มรายการสั่งซื้อ"** จะมี Pop-up Modal แสดงขึ้นมา:

1. **ส่วนหัวบิล (Header Details):**
   - **วันที่สั่งซื้อ:** Date Picker กำหนดวันที่จัดซื้อได้
   - **ผู้สั่งซื้อ:** Input Text ระบุชื่อผู้ทำรายการ
   - **หมายเหตุ:** Input Text ระบุรายละเอียดเพิ่มเติม (Optional)

2. **ตารางกรอกรายการวัตถุดิบ (Dynamic Ingredient Rows):**
   - **ชื่อวัตถุดิบ:** พิมพ์ชื่อวัตถุดิบอิสระ (เช่น แซลมอน, ปลาซาบะ, เบียร์สด, เส้นโซบะ, กุ้ง)
   - **จำนวน:** ระบุจำนวนหน่วย
   - **หน่วยนับ:** เลือกจาก Dropdown (`กก.`, `ขีด`, `ถุง`, `แพ็ค`, `แผง`, `ขวด`, `กล่อง`, `ลัง`, `ชิ้น`, `ลิตร`)
   - **ราคาต่อหน่วย:** ระบุราคาต่อ 1 หน่วย
   - **คำนวณอัตโนมัติ:** ระบบคำนวณราคารวมของแถวนั้นทันที (`จำนวน × ราคาต่อหน่วย`)
   - **ปุ่มเพิ่ม/ลบแถว:** กดเพิ่มรายการ (+) หรือกดลบแถว (ไอคอนถังขยะ) ได้ตามต้องการ

3. **สรุปยอดรวม (Total Cost Summary Box):**
   - คำนวณสรุปยอดเงินรวมวัตถุดิบทุกรายการแบบ Real-time แสดงในกล่องสีเขียวเด่นชัดก่อนกดปุ่ม **"บันทึกรายการสั่งซื้อ"**

## 4. การเชื่อมโยงกับ Owner Dashboard

ข้อมูลการจัดซื้อจากตาราง `purchase_orders` และ `item_ingredients` จะส่งตรงไปแสดงผลใน **Dashboard เจ้าของร้าน**:

1. **Card สรุปยอดต้นทุนวัตถุดิบ:** รวมราคารวมจัดซื้อตามช่วงเวลาที่กรอง (วันนี้ / เมื่อวาน / สัปดาห์ / เดือนนี้ / Custom)
2. **Top 3 วัตถุดิบต้นทุนสูงสุด:** แสดง 3 วัตถุดิบที่ใช้เงินซื้อมากที่สุดในช่วงเวลานั้นๆ พร้อมราคารวม

---

## 5. ระบบนับสต็อกเมนูเสริม (Menu Item Portion Control - Tab 2)

แท็บ **"รายการสต็อกคงเหลือ"** และ **"ประวัติการปรับสต็อก"** ยังคงถูกเก็บไว้เป็นฟีเจอร์เสริมในแท็บลำดับรอง สำหรับกรณีที่ต้องการจำกัดจำนวนจานอาหารบางเมนูเฉพาะกิจหน้าร้าน (เช่น แก้มปลาต้มซีอิ๊ว มีจำกัด 5 จานต่อวัน) โดยไม่กระทบกับแกนหลักของระบบต้นทุนวัตถุดิบ
