## 🎯 Overview
Redesign the **Sales Overview Bar Chart** (`SalesChart.tsx`) in Owner Dashboard to display fixed 7-slot hourly bars for Today/Yesterday, 7-slot daily bars for This Week, and horizontal scrollable daily bars for This Month / Custom date ranges.

---

## 📐 Chart Grouping Logic

### 1. Today & Yesterday (`today` / `yesterday`)
- **Hours Slotting:** Fixed 7 hourly slots: `17:00`, `18:00`, `19:00`, `20:00`, `21:00`, `22:00`, `23:00`.
- **Pre-filled Slots:** All 7 slots are generated by default (0 revenue if no orders in that hour).

### 2. This Week (`this_week`)
- **Days Slotting:** Fixed 7 daily slots representing Monday to Sunday (`จ.`, `อ.`, `พ.`, `พฤ.`, `ศ.`, `ส.`, `อา.`).
- **Pre-filled Slots:** All 7 slots generated by default.

### 3. This Month (`this_month`) / Custom Range (`custom`)
- **Daily Slotting:** Generates 1 slot for each day of the selected month / custom date range (e.g. Days 1 to 30/31).
- **Horizontal Scroll (`overflow-x-auto`):** Fixed width per bar (e.g., `min-w-[28px]` per bar container), allowing smooth horizontal scrolling when bars exceed card width.
- **Sticky Y-Axis:** Y-axis grid labels remain fixed on the left while the bars container scrolls smoothly.

---

## 🎨 UI & UX Styling
- **Bar Styling:** Gradient `from-red-600 to-rose-400` with hover state `from-red-700 to-rose-500`.
- **Interactive Tooltip:** Shows total revenue `฿` and bill count when hovering/touching a bar.
- **Peak Sales Bar Highlight:** Highlight the highest revenue bar with a distinct subtle ring/glow.
